## 这版改了什么

短视频动画脚本从空脚手架变成可出片的规则。给定一个场景或思路，技能自行展开；给定一段小说或文案，技能改写成可拍分镜。全片不少于 90 秒，每段不超过 15 秒且至少三个分镜，默认 2D 动漫。每镜写景别、运镜、动作、台词、旁白、音效、光影、场景、画面提示词和图生视频提示词。每个出镜角色有一条纯白背景、A-pose 的生图提示词。触发语没有增删。

## 使用者要做什么

- [x] 用新 zip / 新目录替换已安装的 Skill
- [x] 无需迁移工作区（默认）
- [ ] 其他：无

## 不兼容说明

已安装的 0.1.0 没有这些细则，继续用旧包得不到新脚本格式。重装后，默认画风从「不限定」改为 2D 动漫；同一条请求里写明其他画风时，整片改用该画风。
