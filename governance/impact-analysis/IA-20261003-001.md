# Impact Analysis

## CR ID

CR-20261003-001

## Summary

0.2.0 为短视频动画脚本补上即梦向分镜、画面与图生视频提示词、角色白底 A-pose 生图，以及「思路展开 / 小说改写」两种入口。`SKILL.md` 与 `skill.json` 的契约段一并更换。触发短语不改。

## Affected Layers

| Layer | Affected | Notes |
|---|---|---|
| Contract (`SKILL.md` / `skill.json`) | yes | 契约段、路由；版本 0.2.0 |
| Rules (`references/`) | yes | 新增 01、02、03；改 README 索引 |
| Templates (`assets/`) | no | |
| Scripts (`scripts/`) | no | 根 `scripts/` 不改；`governance/scripts/` 不改 |
| Tests (`tests/`) | yes | 填固定四问，新增 `tests/cases-0.2.0.md` |
| Pack / version scripts | no | 只运行，不改脚本 |

## Affected Capabilities

| Capability | Impact | Risk | Need Regression |
|---|---|---|---|

| 缺口记录 | none | 不改 | no |
| 已装 0.1.0 | medium | 旧包没有新规则 | yes，升级记录写明重装 |

## Rollback Plan

1. 回到基线 `governance/baselines/0.1.0/`，用其中同名文件覆盖根上的 `SKILL.md`、`skill.json`、`README.md`、`VERSION`、`CHANGELOG.md`、`references/README.md`。
2. 删除本版新增的 `references/01-intake.md`、`references/02-storyboard.md`、`references/03-characters.md`、`tests/cases-0.2.0.md`。
3. `tests/README.md` 不在基线里。用 `git checkout ea3e3f4 -- tests/README.md` 恢复。
4. 不覆盖、不删除 `0.1.0` 基线。不靠只改 `VERSION` 再跑 `sync_version.py` 来回退契约段。
